This repository contains my solutions for **Lab No. 01** of Object Oriented Programming. All 11 tasks are combined in a single C++ source file, `main.cpp`, with a simple menu to run any task (or all of them).

## Tasks Covered

| # | Task |
|---|------|
| 1 | Store name, age and GPA in variables and print them |
| 2 | Take two integers as input; print sum, difference, product and division |
| 3 | Declare variables of different data types (`int`, `float`, `char`, `string`, `bool`) and print them |
| 4 | Print numbers from 1 to 10 using a loop |
| 5 | Print the multiplication table of 5 using a loop |
| 6 | Find the sum of all even numbers from 1 to 100 |
| 7 | Check whether a number is prime (using a loop) |
| 8 | Function `add(int a, int b)` that returns the sum |
| 9 | Function `factorial(int n)` that returns the factorial |
| 10 | Function `isEven(int n)` that returns `true` if even, otherwise `false` |
| 11 | Function `power(int base, int exponent)` without using built-in `pow` |

## Concepts Practiced

- Variables and data types
- Input / output with `cin` and `cout`
- Arithmetic operators and type casting
- Loops (`for`) and conditions (`if / else`)
- Functions and return values

## How to Compile and Run

Requires a C++ compiler such as `g++`.

```bash
g++ main.cpp -o lab01
./lab01
```

On Windows:

```bash
g++ main.cpp -o lab01.exe
lab01.exe
```

When the program starts, enter a task number (`1`–`11`) to run that task, or `0` to run all tasks in order.
