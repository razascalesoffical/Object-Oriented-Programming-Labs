# Object Oriented Programming Labs

My complete **Object Oriented Programming (C++)** lab work at **Abasyn University Islamabad**: 10 labs covering the core ideas of OOP, from C++ basics to classes, inheritance, abstraction, polymorphism and operator overloading.

## Labs Overview

| Lab | Topic | What it covers |
|-----|-------|----------------|
| Lab 01 | C++ Basics | Variables, data types, input/output, loops, functions |
| Lab 02 | Classes in C++ | Defining classes, setters and getters, constructors |
| Lab 03 | Constructors and Destructors | Defining constructors and destructors in classes |
| Lab 04 | Constructor Types and Destructors | Default, parameterized and copy constructors, destructors |
| Lab 05 | Inheritance (Single, Multilevel) | Base and derived classes, single and multilevel inheritance |
| Lab 06 | Inheritance (Hierarchical, Multiple, Hybrid) | Hierarchical, multiple and hybrid inheritance |
| Lab 07 | Abstraction | Abstract classes and pure virtual functions |
| Lab 08 | Polymorphism | Method overriding and virtual methods |
| Lab 09 | Static Members | Static data members and static member functions |
| Lab 10 | Operator Overloading | Compile-time polymorphism and overloaded operators |

## OOP Concepts Covered

- **Classes and Objects** – data members, member functions, setters and getters
- **Constructors and Destructors** – default, parameterized and copy constructors
- **Inheritance** – single, multilevel, hierarchical, multiple and hybrid
- **Abstraction** – abstract classes and pure virtual functions
- **Polymorphism** – runtime polymorphism (virtual functions, overriding) and compile-time polymorphism (operator overloading)
- **Static Members** – shared data and class-level functions

## How to Run

Requires a C++ compiler such as `g++`.

```bash

g++ main.cpp -o lab
./lab
```

On Windows:

```bash
cd Lab-01
g++ main.cpp -o lab.exe
lab.exe
```
